# Overview. 
This document defines the primary user personas for the AI-native Software Engineering Workspace. Understanding our target users helps guide product decisions, prioritize features, and ensure the platform solves real engineering problems rather than adding unnecessary complexity. 
Primary Persona: Full Stack Software Engineer. Responsible for designing, implementing, testing, documenting, and maintaining product features. 
## Goals: 
Deliver high-quality software faster, reduce repetitive tasks, keep technical decisions documented, and spend more time solving problems and less time managing tools. Retain project context throughout development. 
## Pain Points: 
Constant context switching between multiple applications. Knowledge scattered across systems. Repeating the same explanations in meetings, chats, and documents. Difficulty finding prior technical decisions. AI tools working in isolation can increase cognitive load. 
Success criteria. The user can complete common software development activities without excessive context switching.
